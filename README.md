# Personal portfolio (static)

This workspace contains a minimal static site scaffold for a Typographic Resume portfolio (Sprint 1) for Liyan.

Quick test:

1. Open `index.html` in a browser (double-click or use a simple HTTP server).

Simple local server (Python 3):

```bash
python -m http.server 8000
# then open http://localhost:8000/
```

GitHub Pages:

- Push this repository to GitHub. For a project site, enable Pages from the `main` branch `/ (root)` or use the `gh-pages` branch. Alternatively, put files in a `docs/` folder on `main`.

Reflection

For this homework assignment, I learned how to instruct AI to create a personal website and deploy the website to Github. To make sure AI can follow my directions correctly, I broke the project down into smaller steps. When thinking about what to ask AI, I realized that my prompts should be specific so that AI can fully understand what is expected from it. For example, if my prompts are too general and lack specific details, then AI may incorrectly follow directions and create a website that does not align to my expectations. To address this problem, I ensured that the prompts I sent to AI are specific so AI knows exactly what to do.
